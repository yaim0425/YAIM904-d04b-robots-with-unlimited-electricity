# YAIM0425 d04b – Robots with Unlimited Electricity ⚡🤖

## 📦 Description

**YAIM0425 d04b – Robots with Unlimited Electricity** adds special versions of construction and logistic robots that **do not consume electricity while working**.

These robots still require an **initial charge** to activate, but once deployed, they can operate indefinitely without draining power.

This MOD is ideal for large-scale factories, long-distance logistics, or environments where charging infrastructure is inconvenient.

---

## ⚙️ How it works (Player view)

* The MOD creates **copies** of vanilla construction and logistic robots
* Robots must be **charged once** before starting to work
* After activation, they **no longer consume electricity**
* All other behaviors remain identical to standard robots

No settings or configuration are required.

---

## ⚠️ Warnings

* 🚨 **This MOD significantly alters game balance**
